# RagnaModManager Hammer Samples

Source projects and built `.rhammer` examples for custom Ragnarock hammers. Each sample contains its editable source art, UE 4.27 authoring project and package instructions.

- [Azure Blockhead](azure-blockhead-source/README.md): original low-poly mesh, textures, icon, combo-responsive materials, Windows cook scripts, and a verified package.

Follow the [RMM custom hammer authoring guide](https://github.com/Brollyy/RagnaModManager/blob/master/docs/custom-hammer-authoring-ue4-27.md) to make a package from your own assets.
